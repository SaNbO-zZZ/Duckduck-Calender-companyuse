## 项目定位

鸭鸭日历是公司内部使用的飞书妙搭请假、调休、晚到和提前离开登记应用，包含日历展示、法定节假日与补班、合肥瑶海天气、鸭鸭动画、通知和版本知会等能力。线上运行工程以 GitHub 仓库的妙搭代码为准；单文件 HTML 与历史素材用于本地设计、复核和追溯。

## 后续工作约定

每个变更都按下面顺序处理：

1. 读取本文件、`README.md`、相关工程记录和已有测试。
2. 在当前工作区修改源代码、素材或文档；不回到旧目录开发。
3. 运行与变更匹配的测试、类型检查、Lint 和构建；发布类变更补充线上妙搭核验。
4. 更新本文件的“更新日志”和对应版本记录，生成或更新同名 DOCX。
5. 把摘要、版本号、GitHub 提交或 Tag、妙搭 release、验证结果和必要截图链接写入同一份飞书更新日志。
6. 提交并推送到 `origin`。需要协作评审时沿用现有 Git 工作流和 Pull Request 模板。

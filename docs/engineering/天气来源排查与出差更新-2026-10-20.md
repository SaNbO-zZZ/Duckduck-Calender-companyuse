# 鸭鸭日历：天气来源排查与“出差”更新（2026-10-20）

## 当前天气为何显示“阴天”

正式应用后端 `server/modules/calendar/calendar.service.ts` 的 `weather()` 仍请求 `api.met.no/weatherapi/locationforecast/2.0/compact`，坐标固定为北纬 31.8696、东经 117.3154（合肥市瑶海区附近）。它读取最近一个整点的 `symbol_code`、下一小时预报雨量与云量，并缓存最多 30 分钟。这是挪威气象局的**逐小时预报**，不是所在地实时降水观测或雷达图。2026-10-20 排查时，该接口当时返回 `cloudy`、下一小时预报雨量 `0.0`，因此代码按既定规则显示“阴天”。用户在现场看到降雨与预报不一致，属于此数据源在局地、短时降水上的漏报；缓存与整点粒度还会推迟变化的显示。

## 中国数据源核查

- 中国天气网 [SmartWeatherAPI 官方说明](https://www.weather.com.cn/wzfw/smart/weatherapi.shtml) 称它是中国气象局面向开发者的接口，须填申请表并经审核后领取接口信息。当前妙搭应用线上环境未配置此接口凭据。
- 墨迹天气 [企业 API 产品](https://www.mojicb.com/product/api) 提供实况与分钟级降水服务，适合核查短时降雨；但其 [售后与商务说明](https://www.mojicb.com/support/after_sales) 明确说通常每账号只有 7 天免费试用，未找到适合全员长期运行的永久免费实况接口。墨迹天气也不是用户指定的中国气象局官方接口。

**状态：尚未切换天气来源。** 不把未经授权或即将过期的试用接口部署到全员应用。获得中国天气网正式接口授权后，需要确认其服务包含合肥市瑶海区的实时降水或分钟级短临数据、配额、商用条款，再把凭据存为妙搭线上环境变量，替换后端数据适配器，测试晴／阴／雨／雪／强风映射及失效降级，最后发布。密钥不写入 HTML、仓库或会话记录。

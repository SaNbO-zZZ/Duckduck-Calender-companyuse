## 发布链路与当前来源

- 妙搭原工程的真实提交顺序保留；原 `sprint/default` 分支在本仓库作为 `main` 延续。
- `source/鸭鸭日历.html` 是本地单文件源的当前归档。妙搭的 React/Nest 适配工程位于 `client/` 与 `server/`，两者不能互相冒充自动同步。
- `v3.2.1` Tag 保留首次上线提交 `cb2d905`；`v3.2.1+roster.1` Tag 对应本轮最终工程快照 `c97af44`。实际运行代码发布提交为 `bf9ebfb`，随后将名单读取策略作为数据库迁移发布。GitHub `main` 还包含历史归档、图文和工程文档提交，不能将其 `HEAD` 当作线上发布 SHA。
- 飞书妙搭 release ID、问题根因与验收边界记录在 `docs/engineering/`；机器人“已发送”与用户“已阅读”仍是不同状态。

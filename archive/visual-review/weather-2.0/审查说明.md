# 鸭鸭日历 · 天气背景审查

状态：本地候选已可审查，未正式发布。飞书正式页面仍为 v10/1791393770838。

用户要求：逼近 iOS 天气的真实光线、水珠折射、雨雪深度；信息一眼可读；小雨、大雨、强风明显不同；遵循系统减少动态效果偏好；上线前提供天气画面供用户审查。

实现目标：原生 WebGL 着色器，背景与业务组件分离；自动降画质及静态备用；隐藏时暂停；背景不阻挡点击、不折射文字；复用现有瑶海区天气请求，不增加员工数据外传。

审查范围：晴天、阴天、小雨、大雨、强风、大雨加强风、雪天，以及夜间、静态模式。审查覆盖只存在预览环境，正式页不能受演示控件影响。

天气强度按已有 WWO 天气码分类；precipMM 时间窗未确认，不假设 mm/h；windspeedKmph >=39 为强风视觉阈值，不表示官方预警。未知天气使用中性背景。

## 打开方式

- 打开 `gallery.html`：8 个天气场景的实际渲染图、约 8 秒视频及页面示意。
- 打开 `review.html`：实时切换天气、白天/夜晚与静态模式；支持手机宽度预览。
- `天气效果对照.png` 用于快速比较。强风的差别应看视频，静帧不能表现移动速度。

本地页面使用演示场景，不连接员工数据，也不提交请假。正式日历的表单和通知逻辑未在这个本地页面复制。

## 已做的视觉调整

晴天采用柔和光晕、光束与轻微光斑；阴天采用连续缓慢变化的灰蓝云层。小雨与大雨在雨丝密度、长度、水珠频率上区分；大雨加强风增加倾角和运动强度。玻璃水珠向下滑落，并偏移采样背景实现折射，正文不会被折射。雪天使用三层尺寸、速度和散焦不同的雪花。夜间使用暗色天空与月光。

已修复云层块状纹理、雨天透出太阳、水珠上移、雨滴拖尾截断、风雨预设参数相同等问题。最后一轮适度加强了光束和水珠边缘，仍以阅读日历内容为先。

建议审查：云层是否有足够真实的层次；水珠在正文外是否可见但克制；大雨与大雨加强风的动态区别是否明显。现阶段是程序化天气视觉，不能视为已完全复刻 iOS 天气。

## 性能与可访问性

本地桌面浏览器观察约 60 FPS；390 × 844 CSS 像素的窄屏预览观察约 30 FPS，实际 canvas 为 485 × 1053，约 51 万像素。8 个最终视频已通过解码、尺寸和时长核对。

代码包含帧率与分辨率限制、低帧率降画质、隐藏页面暂停，以及 `prefers-reduced-motion` 监听。手动静态模式已实测，保留当前天气的静帧并停止动画。上述桌面浏览器结果不等于飞书手机真机性能；系统设置在飞书内的传递、低性能设备降级、上下文恢复与长期发热耗电仍待实际设备验证。

## 同步与上线限制

飞书草稿已有可运行的 WebGL 背景，但 AI 编辑额度已用尽，末轮修订目前只保存在本地。未找到已确认可用的手动源码编辑入口。可移植源文件为 `review.template.html` 与 `weather-fragment.review.glsl`，最终展示文件为 `review.html`。

恢复飞书编辑能力后，将末轮着色器、场景参数和性能限制同步到草稿，保留现有业务组件，再验证桌面与手机。用户审查并明确同意后才正式发布。正式 HR、通知工作流和权限的既有待核事项不由本次视觉预览替代。

## 文件来源

最终 `候选-*.png` 与 `候选-*.webm` 均通过浏览器原生操作，从实际运行的 WebGL canvas 导出。`export-provenance.json` 记录下载来源，`review-manifest.json` 记录校验值，`video-verification.json` 记录媒体参数。

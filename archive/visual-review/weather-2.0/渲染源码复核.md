# 渲染源码复核

来源：预览审查按钮导出的 weather-renderer-review (1).json，实际 shaderVersion=v2.0-rewrite。

实际初始化失败原因：GLSL ES 1.00 的整数 min 无匹配重载。fragmentShader 第 284 行为 `dropCount = min(dropCount, 30);`，真实编译日志同时报告无法把 float 赋给 int。已要求改为整数条件截断。

水珠实现复核：refractOffset 计算后未使用；源码明确只以高光和颜色变化模拟。该版本尚未满足用户对真实背景折射的要求。已要求使用偏移 UV 重采样程序天空，或离屏天空纹理采样，保持 DOM 文本不被折射。

兼容性追加要求：反向 smoothstep 改为 `1.0 - smoothstep(小值, 大值, x)`；光源和水珠距离按画幅比例校正。

发布状态：本次所有实现与修复均只在草稿，未点更新发布。完成修正后需重新导出当前源码及实际图片，旧版诊断与源码仅用于审计，不作为最终效果。
